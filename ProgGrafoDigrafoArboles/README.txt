COMO ABRIR EN INTELLIJ IDEA:
1. Descomprime esta carpeta.
2. Abre IntelliJ IDEA.
3. Selecciona File > Open.
4. Abre la carpeta 3er_Parcial_IntelliJ.
5. Abre src/Main.java.
6. Da clic en el triangulo verde junto a public static void main.
7. Ejecuta el programa.

COMO PROBAR LA RUTA ACAPULCO A CDMX:
1. Elige 1, 2 o 3 segun el proyecto.
2. Elige opcion 2: Ruta mas corta con Dijkstra.
3. Nodo origen: 0
4. Nodo destino: 10
